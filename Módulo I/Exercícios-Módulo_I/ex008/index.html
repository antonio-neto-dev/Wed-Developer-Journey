Trabalhando com Listas

Listas Ordenadas

Uma lista ordenada é uma lista em que a ordem importa, em que os itens apresentam uma ordem sequencial e um símbolo que represente essa ordem sequencial. As listas ordenadas em HTML possuem dois parâmetros principais: type e start. O parâmetro type serve para indicar o tipo do símbolo que representa a ordem da lista, podendo ser: 1, A, a, I e i, com I e i representando o formato em algarismos romanos. Já o parâmetro start é utilizado para indicar em qual posição sua lista deve começar, por exemplo "start = '4'" - start é um parâmetro númerico, então mesmo que você esteja utilizando um type = "a", por exemplo, você não pode usar um "e" para dizer em qual posição sua lista deve começar, mas sim um número inteiro representando a posição de determinado elemento. Exemplo de lista ordenada a seguir:

  1. Acordar
  2. Mandar mensagem para minha namorada
  3. Tomar café da manhã
  4. Arrumar a casa
  5. Estudar o conteúdo programado

Listas Não Ordenadas

Uma lista não ordenada é uma lista em que a ordem dos itens não importa, podendo iniciar e terminar com qualquer um deles que não fará diferença. Geralmente utilizadas em menus, navegação, listas de compras, etc. O único parâmetro relevante que uma lista não ordenada possui é o type, que pode ser um disc, um circle e um square, que como os nomes dizem, irá mudar a aparência ou para um disco, ou para um círculo vazio ou para um quadrado preenchido, com o símbolo padrão sendo o disco. Exemplo de lista não ordenada a seguir:

  • Alface
  • Tomate
  • Mamão
  • Laranja
  • Cenoura
  • Cebola
  • Manga

Listas Aninhadas

É possível aninhar listas e inclusive misturar vários tipos de listas diferentes, sejam ordenadas, não ordenadas ou de definição. Isso é amplamente utilizado na criação de menus. Exemplo de lista aninhada e mista a seguir:

Meus jogos favoritos

  • Nintendinho
    1. Mario Bros
      • Super Mario Bros
      • Mario: Lost Levels
    2. Ninja Gaiden
      • Ninja Gaiden III
  • Super Nintendo
    1. Super Mario World
    2. Donkey Kong
      • Donkey Kong Counrty III
      • Diddy's Kong Quest
  • Playstation I
    1. Final Fantasy
      • Final Fantasy VII
      • Final Fantasy IX
    2. Castlevania
      • Simphony of the Night

Lista de Definições

Como diz o nome, ele é uma lista em que seus itens são termos com suas definições, atuando como um dicionário. Auxilia bastante mecanismos de busca quando um usuário digta, por exemplo, a definição de HTML, os mecanismos de busca irão priorizar sites que possuam listas de definição, isso valoriza seu site. É uma lista sem demarcadores, mas muito útil em alguns casos. Exemplo de lista de definição a seguir:

HTML
Linguagem de marcação utilizada para a criação do conteúdo do site e por dar significado aos seus elementos.
CSS
Linguagem de seletores, utilizada para a estelização e desing da sua página.
JavaScript
Linguagem de programação responsável pela interatividade do seu site.
