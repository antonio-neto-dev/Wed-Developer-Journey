Usando links externos

Venha conhecer o repositório do GitHub do Gustavo Guanabara

Como é possível analisar, caso esteja visualizando o código-fonte, a tag <a> possui alguns parâmetros muito importantes, como hreflang, target e rel. Definição dos parâmetros a seguir:

hreflang:
Parâmetro utilizado para informar ao navegador e seus leitores de tela o idioma do site qual o usuário vai ser encaminhado ao clicar no link. Muito importante caso o usuário deseja utilizar o mecanismo de tradução automática.
target:
Parâmetro utilizado para informar onde esse link deve ser aberto, caso não seja utilizado, ao abrir determinado link, ele irá sobrepor o seu site e dificilmente o usuário irá voltar para o seu site depois disso (esse é um comportamento desejado caso o usuário vá continuar usando nosso site, mas caso em que não, devemos evitar a sobreposição). Por isso, podemos e devemos espeficar os nossos alvos da abertura do link.
target = "_blank":
Utilizado para informar que determinado link deve ser aberto em uma janela vazia do navegador e evitar seu site seja sobreposto.
target = "_self":
Vai abrir o linkl na janela ou frame atual, ou seja, sobrepondo o site aberto ao seu, sendo o comportamento padrão dos links.
target = "_top":
Vai desfazer todos os frames e abrir o link no navegador completo.
target = "_parent":
Similar ao uso do _top em uma referência à janela mãe.
target = "nome-do-frame":
Caso esteja usando frames, indicar o nome da janela a abrir.
rel:
Recurso utilizado para indicar a natureza do destino do link.
rel = "next":
Indica que o link é para a próxima parte do documento atual.
rel = "prev":
Indica que o link é para a parte anterior do documento atual.
rel = "author":
Indica que é um link para o site do autor do artigo atual.
rel = "external":
Indica que é um link para outro site que não faz parte do site atual.
rel = "nofollow":
Indica que é um link para um site não endossado, como um link pago.

Em relação ao exemplo de link utilizado, ele é um link externo, por isso devemos informar a URL completa do link, com seu protocolo, subdomínio, domínio, TLD e se precisar, informar também o caminho.
