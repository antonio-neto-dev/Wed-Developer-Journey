Código-fonte / Pré-formatação

A tag code formata o texto para uma fonte mono espaçada, melhorando a leitura do código, pois todos os caracteres ocuparão o mesmo espaço, assim: document.getElementById('teste').

A tag PRE formata o texto da forma como foi escrito, considerando as identações e espaçamentos aplicados, muito útil e utilazada em conjunto com a tag CODE quando queremos exibir códigos na nossa página HTML. Desta forma:


num = int(input('Digite um número inteiro: ))
if num % 2 == 0:
    print(f'O número {num} é par.')
else:
    print(f'O número {num} é ímpar.')
print('Fim do programa')

Qual é a diferença entre usar aspas e a tag <q>? A diferença é a semântica, pois a tag <q> possui siginificado, já as aspas simples não possuem significa dentro de HTML, apenas modificam a forma. Por isso, devemos avaliar quando usar aspas simples e quando usar a tag <q>.

Texto invertido

Irei invertir esse texto usando uma tag semântica inútil para texto invertido, não serve pra nada essa tag, apenas pra irritar.

Como podemos ver, acabei de colocar o texto para ser lido da direita para a esquerda, usando o parâmetro "rtl", que significa rigth to left. Se eu usasse o parâmetro left to right, seria a mesma coisa que deixar o texto normal, então é um parâmetro meio inútil.
