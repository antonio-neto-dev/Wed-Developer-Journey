Links de Download

Antes de utilizar links de download, devemos entender um pouco sobre media types, que você configura no atributo type. A seguir estão os media types mais amplamentes utilizados no mercado:

  • application/zip
  • application/pdf
  • text/html
  • text/css
  • text/javascript
  • video/mp4
  • video/H264
  • video/JPEG
  • audio/aac
  • audio/mpeg
  • font/ttf
  • image/jpeg
  • image/png

Adendo: para fazer o download de determinados arquivos devemo utilizar o atributo download dentro da tag <a> e especificar corretamente o nome do arquivo que queremos disponibilizar para download. Depois, especificamos o tipo do arquivo que está sendo baixado utilizando o atributo type.
